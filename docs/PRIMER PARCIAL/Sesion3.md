# Práctica 2

En esta práctica hicimos algunos circuitos controlados con ayuda del ESP32, el cual es un microcontrolador de bajo costo el cual consta con wifi y bluetooth.

Lo primero que hicimos con el ESP32 fue alimentarlo para encender un led, despues hicimos un circuito básico para hacer que el led parpadearay aprendimos algunos comandos básicos. 

Despues hicimos un código para que se encendieran dos focos a la vez.
