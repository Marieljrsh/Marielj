# Práctica 1 

En esta práctica aprendimos sobre la electrónica. Hicimos dos circuitos básicos: uno para encender un LED y otro para hacerlo parpadear.

Para el primer circuito utilizamos un LED azul y una resistencia de 220 Ω. Lo que buscamos fue hacer un circuito básico para encender un LED.

Para el segundo circuito usamos un módulo 555, tres resistencias y tres capacitores.

Buscamos hacer un temporizador para que el LED parpadeara cada cierto tiempo. Al prenderlo, nos dimos cuenta de que, al tener un capacitor electrolítico, funciona perfectamente; pero, al usar un capacitor de cerámica, el foco parecía no parpadear.

Cuando terminamos el segundo circuito, lo conectamos al osciloscopio. Ahí pudimos observar cómo se comporta la señal eléctrica. También nos dimos cuenta de que el capacitor de cerámica sí hacía que el LED parpadeara, solo que lo hacía tan rápido que no podíamos percibirlo a simple vista.
